Concentrator Monitor · User Manual

How to configure, run and troubleshoot the TCP connection monitor.

📡 Overview

Concentrator Monitor is a desktop application that counts ESTABLISHED TCP connections on a configurable port in real time, using the standard Windows netstat command. It is intended for Assa Abloy Marine Division technicians who need to quickly verify active connections to a Visionline concentrator.

ℹ️ How it works
The app runs the following command at a configurable interval and counts the matching lines: 
netstat -na | findstr ":PORT" | findstr "ESTABLISHED" | find /c "ESTABLISHED"

⬡ Monitor View

This is the main screen. It displays the live count of ESTABLISHED connections.

1

Click "Start Monitoring"

Press the blue button in the Details panel. The counter will refresh automatically at the configured interval.

2

Read the counter

The large number in the centre shows the total ESTABLISHED connections. The port badge (e.g. :7799) shows which port is being monitored.

3

Stop when done

Press "Stop Monitoring" to pause polling. The last known count stays on screen.

💡 Status colours
Green — monitoring is running normally.
Red — an error occurred (e.g. netstat not available). Check the Details panel for the message.

⚙️ Settings

Open the Settings view from the sidebar to change these values:

FieldDefaultDescription
Port Number 7799 The TCP port to monitor. Default Visionline concentrator port: 7799.
Refresh Interval 5 s How often (in seconds) the command is re-run. Range: 1 – 3600.
ℹ️ Persistence
Settings are saved to disk on this machine only (via Electron's config store). They survive app restarts. Credentials are never sent to the cloud.

🔧 Troubleshooting

!

Counter shows "–" or does not update

Make sure you have clicked Start Monitoring. If the problem persists, verify that netstat is available by opening PowerShell and running netstat -na.

!

Count is always 0

Check that the port in Settings matches the port the concentrator is actually listening on. Use netstat -na | findstr LISTENING to list active listening ports.

!

App crashes on launch

Run the app from PowerShell with npm run dev to see error output. Check that all dependencies are installed with npm install.
